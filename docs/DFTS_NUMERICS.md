## Newly found inherited bug

IDFT65536 indexed its radix-4 twiddle groups at vector offsets 0, 4096, 8192.
Each group is 16384 complex values, or 2048 256-bit vectors. The correct offsets
are 0, 2048, 4096. The old third group is outside the 6144-vector array.
The independent audit found a 76.5279% unitary relative L2 error before this
repair, despite the earlier zero/determinism checks passing. The corrected error
is 0.3396%. The patch is included in `patches/k3-A-dfts-correctness.patch`.

## Method and fixed acceptance rule

- NumPy 2.3.5 complex128 FFT is independent of the OAI implementation.
- Reproduce the harness xorshift32 stream and C signed remainder exactly.
  Real/imaginary components are bounded by 1023; all four packed lanes receive
  separate complex input values. Compare along the sample axis, not lane axis.
- For scale=1 compare with FFT/sqrt(N), or IFFT*sqrt(N). Use the fixed
  source-defined gain, never a fitted gain, for the pass decision.
- **DFT12 is an explicit source-contract exception**: `dft12` ignores scale_flag
  and returns an unscaled transform. `nr_ulsch_demodulation.c` case 12 applies
  normalization separately using 9459. Its audit therefore uses raw FFT.
  The initial blanket unitary check failed this case; inspection established
  this existing contract. The implementation and 1% threshold were not changed
  to hide the exception. JSON retains the unitary mismatch as a diagnostic.
- Project engineering gate: complex relative L2 error <=1%, no imaginary output
  for the origin impulse, and exactly zero inactive packed lanes for that impulse.
  This threshold is not an OAI or 3GPP conformance requirement.
- Inspect both scale flags (178 combinations); scale=0 is diagnostic only because
  internal stage scaling varies by transform. Fitted complex gain and residual
  are recorded for diagnosis, not used to excuse amplitude errors.

## Remaining limits / next integration gate

Only one deterministic random seed plus the existing origin impulse is assessed
against FFT numerically. High-amplitude saturation, additional seeds, shifted
impulses/tones, unaligned buffers, cross-VLEN behavior, and a bit-exact scalar
fixed-point oracle remain outside this gate. Output canaries do not prove the
absence of all input overreads. No running gNB, live A source or service changed.
Next, build an isolated gNB against the corrected module and verify loading and
adapter contracts without replacing or restarting the live deployment.
