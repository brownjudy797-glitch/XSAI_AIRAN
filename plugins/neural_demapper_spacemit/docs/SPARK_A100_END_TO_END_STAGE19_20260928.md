# Stage 19：K3 A100 神经网络解调器端到端实验

## 结论

Stage-18 SpaceMIT EP 神经网络解调器已经真实进入 `nr_ulsim` 上行接收链，
完成了 FFT、信道估计、均衡、神经解调、解扰、LDPC 和 RX 返回的配对实验。
合批接口也按预期工作：每 500 帧包含 6,000 个逻辑符号调用，实际只执行
500 次 3312-RE A100 推理。

但是当前候选没有通过端到端验收：

- 6 dB 聚合 BLER 从传统解调器的 34.93% 上升到 61.20%；
- 6.5 dB 聚合 BLER从 1.93% 上升到 8.60%；
- 全矩阵平均 RX wall time 从 1055.479 us 增加到 1248.862 us，增加
  193.383 us（18.32%）；
- 平均 p99 从 1131.419 us 增加到 1316.266 us，增加 184.847 us
  （16.34%）。

因此当前 A100 路径证明了“能正确加载、合批并完成解码流程”，但不能替代
传统解调器，也不进入 gNB/RF 部署。

## 实验设计

两种后端使用相同的 seed、SNR、MCS、PRB 和接收链参数，每个 seed/SNR
都启动独立进程，并交替后端顺序以减小温漂/调度漂移影响。

| 项目 | 设置 |
|---|---|
| 仿真器 | 隔离构建 `nr_ulsim_spacemit_batch` |
| 信道 | AWGN |
| 种子 | 2609271、2609272、2609273 |
| SNR | 5.5、6、6.5、7 dB |
| 每格帧数 | 500 |
| 总帧数 | 12,000（每后端 6,000） |
| 调制/调度 | MCS 10、24 PRB、单层、单次 HARQ |
| 传统 LLR 标度 | 1/16 |
| 神经 LLR 标度 | 8 |
| A100 | CPU8–15，8 线程，1 stream，共享 intra-op 池 |
| 模型 | 固定 3312×FP16，2→32→32→4 Spark MLP |
| 时延区间 | `FFT_rotation_to_RX_return`，前 10 帧 warmup 不计时 |

这里的“端到端”指 `nr_ulsim` PHY 接收链，不包含真实射频、空口、MAC 或核心网。

## BLER 结果

每行聚合 3 个独立种子、共 1,500 帧。所有 24 个进程的 false positive 均为 0。

| SNR | 传统失败 / BLER | A100 神经失败 / BLER | 结论 |
|---:|---:|---:|---|
| 5.5 dB | 1406/1500，93.73% | 1487/1500，99.13% | 神经更差 |
| 6.0 dB | 524/1500，34.93% | 918/1500，61.20% | 神经明显更差 |
| 6.5 dB | 29/1500，1.93% | 129/1500，8.60% | 神经明显更差 |
| 7.0 dB | 0/1500，0% | 1/1500，0.067% | 接近但仍未完全一致 |

质量退化集中在瀑布区，说明高 SNR 的“几乎零错误”不能替代完整 BLER 曲线。
当前主要质量问题是冻结 Spark MLP 输出的软信息可靠度/校准，不是 A100
是否执行到了模型。

下表是每个 SNR 下三个种子的进程均值；单位为 us。

| SNR | 传统 mean | A100 mean | 传统 mean p99 | A100 mean p99 |
|---:|---:|---:|---:|---:|
| 5.5 | 1091.372 | 1273.404 | 1140.339 | 1330.592 |
| 6.0 | 1084.458 | 1272.030 | 1156.726 | 1327.286 |
| 6.5 | 1043.445 | 1246.847 | 1141.102 | 1312.329 |
| 7.0 | 1002.640 | 1203.165 | 1087.508 | 1294.857 |

FFT/rotation 的全矩阵均值为传统 356.764 us、A100 355.131 us，基本不变。
新增约 0.19 ms 位于解调器及其同步推理路径，而不是前端 FFT。

## 完整性门禁

- 24/24 个进程正常产出可解析的 BLER 和两段 RX timing；
- A100 每个 500 帧进程严格记录 6,000 个逻辑符号、500 次物理推理、
  0 次 multi-ULSCH 调用；
- 全部进程 false positive 为 0；
- 实验结束后没有活动的仿真/软基站进程；
- A100 TCM 回到 8/8 blocks free；
- 没有修改或重启在线 gNB。

## 决策与下一步

1. 暂不继续用线程数或缓存掩盖问题；合批已经把每帧 12 次小调用降为 1 次。
2. 先解决模型质量：基于 OAI 均衡后真实张量重新训练或做可验证的 SNR/幅度
   条件校准，并保持本阶段三种子四 SNR 门禁不变。
3. 新模型必须同时满足逐点 BLER 不劣化、false positive 为 0，再讨论 A100
   时延优化。
4. 质量通过后再评估更低开销的厂商接口；当前公开 ONNX Runtime EP 的同步
   调度仍使 A100 路径比传统路径多约 0.19 ms。
